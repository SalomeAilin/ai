# AI 学习之路

从零开始，一步一步学 AI。

## 核心原则

1. **动手 > 看视频**。每个概念都要写出能跑的代码，跑不起来就是没学会。
2. **允许暂时不懂**。很多东西要用过几次才会突然开窍，卡住就先往前走。
3. **每天 30 分钟 > 周末 5 小时**。连续性比强度重要。

## 路线图

| 阶段 | 学什么 | 时间 | 学完能做什么 |
|------|--------|------|--------------|
| 0 | Python 基础 | 4-6 周 | 能写出会跑的小程序 |
| 1 | 调用 AI 接口 | 1-2 周 | 做出自己的聊天机器人 |
| 2 | numpy + 数学直觉 | 3-4 周 | 看懂矩阵、梯度在干嘛 |
| 3 | 手写神经网络 | 3-4 周 | 真正理解 AI 怎么"学习" |
| 4 | PyTorch + mini-GPT | 6-8 周 | 理解 ChatGPT 的内核 |

**为什么阶段 1 在数学前面？** 因为新手最大的敌人是"学两个月做不出东西然后放弃"。
先做出个能用的东西尝到甜头，再回头啃硬骨头，才坚持得下去。

## 怎么用这个仓库

每节课是一个 `.py` 文件。在终端里运行：

```bash
python3 stage0-python/lesson01_hello.py
```

每个文件底部都有【练习】。**必须自己写完练习再看下一课**，光读代码没用。
