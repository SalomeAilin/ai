# AI 学习之路

从零开始，一步一步学 AI。

## 核心原则

1. **先猜，再看答案**。每节课的【先猜】标记处要停下来，先在心里回答。
   猜错比读懂更有价值 —— 错了你才会追问「为什么」，而这个追问才是记忆的钩子。
   直接看答案的那一刻很爽，但那是幻觉，一周后什么都不剩。
2. **动手 > 看视频**。每个概念都要写出能跑的代码，跑不起来就是没学会。
3. **允许暂时不懂**。很多东西要用过几次才会突然开窍，卡住就先往前走。
4. **每天 30 分钟 > 周末 5 小时**。连续性比强度重要。

## 每节课怎么上

```
【先猜】  ← 停下来，心里作答，别往下滚
  ↓
跑代码验证 ← 对了就巩固，错了就有钩子
  ↓
【自测】  ← 凭记忆答，不许往上翻
  ↓
【原理】  ← 到这一步才读解释，不然就白猜了
  ↓
【练习】  ← 自己新建文件写，不是改现成的
```

**答错的题 = 今天真正学到的东西。** 全对反而说明这节课对你太简单了。

## 路线图

| 阶段 | 学什么 | 时间 | 学完能做什么 |
|------|--------|------|--------------|
| 0 | Python 基础 | 4-6 周 | 能写出会跑的小程序 |
| 1 | 调用 AI 接口 | 1-2 周 | 做出自己的聊天机器人 |
| 2 | numpy + 数学直觉 | 3-4 周 | 看懂矩阵、梯度在干嘛 |
| 3 | 手写神经网络 | 3-4 周 | 真正理解 AI 怎么"学习" |
| 4 | PyTorch + mini-GPT | 6-8 周 | 理解 ChatGPT 的内核 |

**为什么阶段 1 在数学前面？** 因为新手最大的敌人是"学两个月做不出东西然后放弃"。
先做出个能用的东西尝到甜头，再回头啃硬骨头，才坚持得下去。

## 怎么用这个仓库

每节课是一个 `.py` 文件。在终端里运行：

```bash
python3 stage0-python/lesson01_hello.py
```

每个文件底部都有【练习】。**必须自己写完练习再看下一课**，光读代码没用。
