# AI 学习仓库

这是一个从应用层出发，结合 AI、Python、SQL、概率论与数据分析的学习仓库。最终目标是完成一个面向全球市场、可复现的量化研究项目。

系统课程、学习进度和每课笔记统一记录在 [AI系统学习.md](./AI系统学习.md)。

## 学习方法

采用“大目标、小步快跑、具体鼓励”的方式，每次 5–10 分钟，只做一个小任务：

1. 明确今天的小成果
2. 看一个完整示范
3. 尝试一句解释、一行代码或一条查询
4. 核对结果，肯定具体进步，解释当前卡点
5. 记录成果，留下下一小步

每完成一个可检查的里程碑就庆祝一次。漏学不扣分、不清零，回来继续当前小任务；进度按实际反馈记录。

## 学习路线

- Python：保存价格、处理数据、编写策略
- SQL 与 SQLite：保存行情并查询实验结果
- 数据分析与可视化：检查数据、计算收益率、绘制图表
- 概率论与统计：概率、条件概率、贝叶斯、分布、期望、方差与抽样
- 全球市场数据：时区、交易日历、币种、汇率与价格调整
- 策略与回测：信号、仓位、费用、滑点与基准比较
- 评估与验证：收益、回撤、时间顺序测试与偏差检查
- AI：理解训练与推理，进行简单模型实验，辅助代码和研究报告
- 项目交付：数据、代码、配置、运行说明和可复现结果

第一版从少量跨市场历史日线数据开始，跑通导入、保存、策略、回测、评估与报告。具体资产和数据来源在数据阶段确定，模拟交易和实盘对接作为后续扩展。

编程、数学与 AI 围绕项目穿插学习，从模拟数据和简单手算开始。学习进度以实际反馈为准，提醒已发送不等于课程已完成。
