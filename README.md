# AI 学习之路

从零开始，一步一步学 AI。

## 核心原则

1. **先猜，再看答案**。每节课的【先猜】标记处要停下来，先在心里回答。
   猜错比读懂更有价值 —— 错了你才会追问「为什么」，而这个追问才是记忆的钩子。
   直接看答案的那一刻很爽，但那是幻觉，一周后什么都不剩。
2. **动手 > 看视频**。每个概念都要写出能跑的代码，跑不起来就是没学会。
3. **允许暂时不懂**。很多东西要用过几次才会突然开窍，卡住就先往前走。
4. **每天 30 分钟 > 周末 5 小时**。连续性比强度重要。

## 每节课怎么上

```
【先猜】  ← 停下来，心里作答，别往下滚
  ↓
跑代码验证 ← 对了就巩固，错了就有钩子
  ↓
【自测】  ← 凭记忆答，不许往上翻
  ↓
【原理】  ← 到这一步才读解释，不然就白猜了
  ↓
【练习】  ← 自己新建文件写，不是改现成的
```

**答错的题 = 今天真正学到的东西。** 全对反而说明这节课对你太简单了。

## 两条轨道

学 AI 要同时长两样东西，只长一样都走不远：

| | **A 轨 · 会写** | **B 轨 · 看懂** |
|---|---|---|
| 方向 | 自下而上，从能敲出代码开始垒 | 自上而下，从你天天在用的 AI 往里拆 |
| 形式 | 跑得起来的 `.py` 文件，带练习 | 概念课，用比喻和最小 demo，不要求写代码 |
| 目录 | `stage0-python/` … | `concepts/` |
| 一周花多少 | 主力，大部分时间 | 一节，30 分钟 |

**为什么不二选一？** 因为单走任何一条都会死在半路：

- **只走 A 轨** —— 前 4-6 周你都在算奇偶数、判断成绩及格，跟 AI 一点关系都没有。
  新手最常见的死法就是死在这一段：「学了两个月，还是做不出任何跟 AI 有关的东西」，然后放弃。
- **只走 B 轨** —— 讲到「向量」要算余弦相似度，讲到「神经网络」要看反向传播。
  你写不出来，就只能看着别人的代码点头。**看懂的东西不属于你**，一周后什么都不剩。

**A 轨给你能力，B 轨给你动力和方向感。** 到 A 轨阶段 2（numpy）两条线开始合流 ——
那时候你不但知道向量是什么，还能自己把它算出来。这是整个计划的目标交汇点。

### A 轨 · 动手路线

| 阶段 | 学什么 | 时间 | 学完能做什么 |
|------|--------|------|--------------|
| 0 | Python 基础 | 4-6 周 | 能写出会跑的小程序 |
| 1 | 调用 AI 接口 | 1-2 周 | 做出自己的聊天机器人 |
| 2 | numpy + 数学直觉 | 3-4 周 | 看懂矩阵、梯度在干嘛 ← **与 B 轨合流** |
| 3 | 手写神经网络 | 3-4 周 | 真正理解 AI 怎么"学习" |
| 4 | PyTorch + mini-GPT | 6-8 周 | 理解 ChatGPT 的内核 |

**为什么阶段 1 在数学前面？** 因为新手最大的敌人是"学两个月做不出东西然后放弃"。
先做出个能用的东西尝到甜头，再回头啃硬骨头，才坚持得下去。

### B 轨 · 概念路线

每节课回答一个问题，不要求你会写代码。**在 A 轨还在打基础的那几周，这条线负责让你一直觉得「我在学 AI」。**

| | 回答的问题 | 前置 |
|---|---|---|
| c01 | Token：大模型怎样读取文字 | 无 |
| c02 | 向量：模型怎样用数字表示含义 | 无 |
| c03 | 神经网络：模型怎样从数据中学习 | 无 |
| c04 | Transformer：模型怎样处理上下文 | c01 c02 |
| c05 | 训练与推理：模型怎样获得和使用能力 | c03 |
| c06 | RAG 与 Agent：模型怎样连接资料和工具 | c04 |

注意 **c03 神经网络** 和 A 轨阶段 3 是同一个东西的两面：
B 轨先让你**知道它在干嘛**，A 轨后面让你**亲手把它写出来**。先懂后写，比直接啃代码省一半力气。

## 怎么用这个仓库

每节课是一个文件。在终端里运行：

```bash
python3 stage0-python/lesson01_hello.py
```

每个文件底部都有【练习】。**必须自己写完练习再看下一课**，光读代码没用。
